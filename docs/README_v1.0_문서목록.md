## 사용 방법

1. `00_` 결정·검토를 먼저 확인한다.
2. `01_` 통합 설계에서 컴포넌트와 범위를 확정한다.
3. `02_` ERD → `03_` 인가 → `04_` REST → `05_` AI/MCP → `06_` 트랜잭션 순으로 세부 계약을 리뷰한다.
4. `07_` AWS 및 `08_` WBS 검수 후 Jira·구현에 반영한다.
